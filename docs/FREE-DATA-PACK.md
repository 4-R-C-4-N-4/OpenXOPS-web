## 1. Scope

This spec covers a CC0 replacement for every X operations data file the
engine needs, plus the tooling that produces and validates it. The pack's
directory layout and file names match XOPS 0.96 exactly, so the engine loads
it unchanged.

It does not cover gameplay changes, new engine features, or the in-browser
edit UI. The edit UI belongs to SOW Phase 3 and is tracked as FDP-UI in
PROGRESS.md.

## 2. Terminology

| Term | Meaning |
|---|---|
| Slot | One file path the engine or a mission expects, e.g. `data/model/soldier0.bmp`. |
| Hard slot | A slot whose path is a string literal in upstream source (152 of them). |
| Map slot | A slot referenced from inside a `.bd1` (up to 10 texture paths, 31 bytes each, relative to the `.bd1`). |
| Manifest | `assets/manifest.json`, the machine-readable list of slots and their constraints. |
| Pack | A directory or zip whose layout is rooted at `data/`. |
| Free Pack | `assets/pack/`, the CC0 pack committed to this repo. |
| Provenance | One record per shipped file in `assets/ASSETS.md` (and `assets/provenance.jsonl`). |
| Style bible | `assets/STYLE.md`, the shared visual rules every prompt inherits. |

## 3. Facts the design rests on (verified)

- F-1: The engine sniffs texture format from file header bytes
  (`CheckTextureFileTypeFlag`, d3dgraphics-opengl.cpp:~880): BM / DDS / FFD8
  / 89PNG. BMP 8, 24 and 32 bit are supported (`LoadBMPTexture`, index ==
  8/24/32).
- F-2: A failed `LoadModel` returns -1, and `RenderModel` returns early on -1
  (opengl.cpp:2225). Missing models don't crash.
- F-3: 152 distinct `"data\\…"` literals in upstream source: model 92,
  article 17, sound 14, map 19 (17 dirs map0–16 + `map10/temp.bd1` + `map10/op.pd1`), sky 2,
  root textures 7 (`char.dds`, `title.dds`, `blood.dds`, `smoke.dds`,
  `mflash.dds`, `scope.dds`, `yakkyou.dds`), briefing 1 (a dir prefix).
- F-4: XOPS 0.96 reference shapes (from openxops.net's file list):
  - Model skins: 256×256 8-bit.
  - Weapon skins and briefing images: 128×128 8-bit.
  - Skies: 256×256.
  - `char.dds`: 512×512 A4R4G4B4 (font + HUD atlas).
  - Effects: 128×128 A8R8G8B8 DDS.
  - Sounds: 22.05 kHz mono 16-bit WAV.
  - Models: text `.x` (`xof 0302txt`), ≤ 139 polygons.
- F-5: Codex CLI 0.163 (`image_generation` feature, ChatGPT login) returns a
  1254×1254 RGB PNG per call. It takes about 60 s. The file is written to
  `~/.codex/generated_images/<thread>/<id>.png`. A seamless-tile prompt
  produced a texture with no visible seams in a 2×2 tiling test.
- F-6: ImageMagick `BMP3:` output defaults to **RLE8 compression**. The
  originals are uncompressed (a 256×256 8-bit file is 66,614 bytes). Always
  pass `-compress None`.

## 4. Manifest schema (contract between tools)

`assets/manifest.json`:

```json
{
  "version": 1,
  "slots": [
    {
      "path": "data/model/soldier0.bmp",
      "kind": "texture",
      "class": "skin",
      "hard": true,
      "source_refs": ["src/parameter.cpp:483"],
      "ref_size": [256, 256],
      "ref_format": "bmp8",
      "alpha": "none",
      "tileable": false,
      "uv_layout": "data/model/up4.x",
      "summary": "Soldier skin (backpack)",
      "priority": "P0",
      "status": "missing"
    }
  ]
}
```

| Field | Values |
|---|---|
| `kind` | `texture` \| `model` \| `sound` \| `map` \| `points` \| `mission` \| `dir` |
| `class` | `hud` \| `effect` \| `skin` \| `weapon_skin` \| `article_skin` \| `sky` \| `map_tile` \| `briefing` \| `model` \| `sfx` \| `other` |
| `ref_format` | `bmp8` \| `bmp24` \| `dds_argb8` \| `dds_argb4` \| `png` \| `x_text` \| `wav_pcm16_mono_22k` \| … |
| `alpha` | `none` \| `black_key` (BlackTransparent) \| `channel` |
| `priority` | `P0` (needed to boot + play one mission) \| `P1` (full weapon/skin roster) \| `P2` (nice-to-have) |
| `status` | `missing` \| `generated` \| `curated` \| `final` |

Updating `status` is the only manual edit. Everything else is generated by
`tools/manifest/build.py` from upstream source plus the reference file list.

## 5. Art pipeline (`tools/artgen/`)

```
artgen.py <slot-path|--class X|--priority P0> [--n 2] [--dry-run]
  for slot in selected:
    prompt = STYLE.md preamble + class template (assets/prompts/<class>.md) + slot.summary
    for i in 1..n:   # candidates
      codex exec --sandbox workspace-write -o <log> "<image-gen instruction: write PNG to assets/work/<slot>/<i>.png>"
    postprocess(candidate):
      resize to slot.ref_size (Lanczos) → if tileable: verify seams (edge-diff metric < SEAM_MAX)
      → quantize per ref_format (bmp8: 256 colours, FloydSteinberg)
      → alpha: black_key → force bg to #000000; channel → keep alpha (DDS/PNG)
      → write BMP3 with -compress None (F-6) / DDS via tools/artgen/dds.py
    append provenance {path, sha256, generator:"codex-cli 0.163 image_generation", prompt, date, license:"CC0-1.0", curated_by:null}
    write contact sheet assets/work/<slot>/sheet.png for human pick
artgen.py pick <slot> <i>   → copies to assets/pack/<path>, status=curated
```

Rules:

- R-1: No reference images from X operations are ever passed to Codex (`-i`).
  Prompts never name "X operations" or its characters. This keeps the pack
  clean-room.
- R-2: Generation runs one Codex call at a time (rate limits). The pipeline
  is resumable because it skips slots whose candidates already exist.
- R-3: Textures that wrap a model UV layout (skins) need the UV template. The
  pipeline renders a UV wireframe from the slot's `.x` file. That model is
  ours, so this is clean-room safe. Phase B: skins come after our own models
  exist. Before that, only tileables, HUD, effects, sky and briefing art are
  generated.
- R-4: Raw candidates in `assets/work/` are git-ignored. Only picked assets
  plus provenance are committed.

## 6. Production order

| Wave | Content | Depends on |
|---|---|---|
| W1 | Map tiles (about 24 tileables: concrete, brick, plaster, wood floor, tile, metal, grate, grass, dirt, asphalt, crate, door, window, …), 5 skies, effects (blood, smoke, mflash, yakkyou, scope) | pipeline |
| W2 | `char.dds` font + HUD atlas, `title.dds` | ASSET-CONTRACT.md glyph/HUD layout |
| W3 | Human rig (`up0–5`, `arm00–02`, `leg`, `walk01–04`, `run01–06` `.x`), weapons (23 `.x`), articles | model tooling (OBJ→`.x`) |
| W4 | Skins for W3 models (UV-template-driven) | W3 |
| W5 | Original maps (`.bd1`) + missions (`.pd1`, `.mif`), incl. title/demo maps (map10, map2/4/5) | map tooling |
| W6 | 14 SFX (CC0 sources or synthesised) | — |

## 7. Configuration reference

| Key | Default | Where |
|---|---|---|
| `ARTGEN_CANDIDATES` | 2 | artgen.py `--n` |
| `SEAM_MAX` | 12.0 (mean abs RGB diff across the wrap edge, 0–255) | artgen.py |
| `QUANT_COLORS` | 256 | artgen.py |
| `PACK_ROOT` | `assets/pack` | all tools |
| `WORK_ROOT` | `assets/work` (git-ignored) | artgen.py |
| `CODEX_TIMEOUT_S` | 300 | artgen.py |
