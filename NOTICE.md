## What is in this repository

- `src/`: OpenXOPS 1.080 source, (c) 2014-2023 OpenXOPS Project / [-_-;](mikan),
  New BSD License (see `LICENSE`). Imported verbatim at tag `upstream-1.080`.
  Every later change is visible with `git diff upstream-1.080 -- src`.
- `src/lib/`: headers and prebuilt Windows libraries for zlib (zlib License),
  libpng (libpng License) and libjpeg (IJG License), as shipped upstream. The
  web build uses Emscripten's own ports instead.
- `src/platform/text/font_atlas.inc`: a bitmap glyph atlas built from the
  Shinonome public-domain bitmap font (12/16 dot), used to render
  CP932/Japanese text in the browser build in place of the Windows system
  font. The Electronic Font Open Laboratory (efont) states Shinonome font
  data, documentation and scripts are Public Domain (license text:
  `assets/fonts/SHINONOME-LICENSE.txt`, matching the upstream `LICENSE`
  verbatim; provenance: `assets/fonts/README.md`). Atlas coverage is Latin-1
  Supplement (hand-authored) plus real hiragana, katakana, full-width
  symbols, and JIS X 0208 level-1/level-2 kanji (~6,900 codepoints) parsed
  by `tools/fonts/gen_font_atlas.py` from the upstream `shnmk16.bdf` /
  `shnm8x16r.bdf` BDF glyph data (any codepoint still outside this table
  renders as a visible outline box, never silently dropped or rendered as
  copyrighted glyph artwork from elsewhere). The CP932 decode table
  (`src/platform/text/cp932_table.inc`, generated by
  `tools/fonts/gen_cp932.py` from Python's built-in `cp932` codec) is
  algorithmically generated and complete for the full CP932 repertoire. See
  `docs/TEXT-RENDERING.md` and `assets/fonts/README.md` for details.
