## What is in this repository

- `src/`: OpenXOPS 1.080 source, (c) 2014-2023 OpenXOPS Project / [-_-;](mikan),
  New BSD License (see `LICENSE`). Imported verbatim at tag `upstream-1.080`.
  Every later change is visible with `git diff upstream-1.080 -- src`.
- `src/lib/`: headers and prebuilt Windows libraries for zlib (zlib License),
  libpng (libpng License) and libjpeg (IJG License), as shipped upstream. The
  web build uses Emscripten's own ports instead.
- `src/platform/text/font_atlas.inc`: a bitmap glyph atlas in the Shinonome
  public-domain bitmap font style (12/16 dot), used to render CP932/Japanese
  text in the browser build in place of the Windows system font. The
  Electronic Font Open Laboratory (efont) states its Shinonome font data,
  documentation and scripts are Public Domain (license text:
  `assets/fonts/SHINONOME-LICENSE.txt`, source:
  https://github.com/code4fukui/shinonome-font). Current atlas coverage is
  Latin-1 Supplement only; hiragana/katakana/kanji glyphs are not yet
  included (missing codepoints render as a visible outline box, never
  silently dropped or rendered as copyrighted glyph artwork from elsewhere).
  The CP932 decode table (`src/platform/text/cp932_table.inc`, generated by
  `tools/fonts/gen_cp932.py` from Python's built-in `cp932` codec) is
  algorithmically generated and complete for the full CP932 repertoire. See
  `docs/TEXT-RENDERING.md` and `assets/fonts/README.md` for details.
